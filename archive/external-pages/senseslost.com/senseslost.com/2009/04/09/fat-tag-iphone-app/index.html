Fat Tag iPhone App

Thursday, April 9, 2009

Here’s a graffiti inspired iPhone and iPod touch app. Fat Tag is simple graffiti tagging app with accelerometer based dripping paint. Another great point about this app, it’s completely free. FAT also provides the source code if anyone is interested in checking it out. You can download Fat Tag app right through the Apple App Store.
