Fat Tag – Open source tagging for the iPhone

Released by  
Theo Watson


A simple graffiti tagging app with accelerometer based dripping paint.
Will update as soon as it has been approved and is available on the app store.

Update: The apps been approved – grab it here: (itunes link) http://itunes.apple.com/WebObjects/MZStore.woa/wa/viewSoftware?id=310458165 – or search for Fat Tag on the app store

Source code for project:
https://fffff.at/fattag-source/OF-006-iPhone-Fat-Tag.zip . If you want to compile and run the code on your device – read some of the guides posted here.

Double tap to clear.
Hit triangle tab to change paint / background color.

Supports multiple strokes.

Enjoy!
Feedback welcome!

A Free Art & Technology project.
FFFFFAT LABS / Muonics 2009
Made with openFrameworks!

Source Code will be posted soon of course :)
